# Logo

- `talently-logo-tile.svg` — BrandLogo con tile (sección 10.1 del maestro, verbatim): tile con `gradient-brand` a 135°, radio ≈ 22 % del lado, y la T blanca (#FFFFFF a #E6DBFF) al 72 %. Variante por defecto: ícono de app, Bienvenida, AppBar y todo fondo con gradiente.
- `talently-logo.svg` — BrandLogo sin tile (sección 10.2, verbatim): la T sola con `gradient-brand` sobre fondo transparente. Solo sobre `color-bg` o `color-surface`, nunca sobre un gradiente.
- Tamaños del componente BrandLogo: sm 32, md 56, lg 72. Los dos trazados son distintos: no se mezclan ni se redibujan.
- Tintas fijas (no usan currentColor): #6D4AFF, #B48CFF, #FFFFFF y #E6DBFF.
