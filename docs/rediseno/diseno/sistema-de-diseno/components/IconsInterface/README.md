# IconsInterface

Los íconos de interfaz nuevos, dibujados en el estilo oficial (viewBox 24, trazo 1,8, puntas y uniones redondeadas, `currentColor`, acentos de relleno entre 18 % y 55 %), en tres colores y ambos temas.

- IconCalendar es la pestaña Actividad. IconGear (rueda dentada) es Ajustes, solo en el AppBar de Perfil; nunca se confunde con IconFilter (sliders).
- Volver = IconArrowLeft (BackButton). Quitar ítem = IconTrash, siempre en `color-text-2`. Fila con navegación = IconChevronRight; Select y SheetPicker = IconChevronDown.
- Tipos de publicación: Empleo = IconOffers, Turno = IconClock, Servicio = IconTool, Clase = IconBook.
- IconShield es la verificación (VerificationBadge, punto de avatar). IconBoost es exclusivo de PromotedBadge «Destacado» y de «Impulsa tu perfil»: nunca junto a IconShield.
- IconAlert e IconInfo son los únicos íconos del Banner y de los errores de campo.
- Agregados para módulos siguientes: IconChevronDown (Select), IconSend e IconAttach (Composer).
- Inter no trae flechas ni checks: esos signos siempre se dibujan con estos íconos.
