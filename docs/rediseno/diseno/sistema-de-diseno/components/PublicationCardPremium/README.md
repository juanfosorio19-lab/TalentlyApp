# PublicationCard · Premium (F3)

La publicación Premium es la misma PublicationCard con el PromotedBadge «Destacado» arriba a la derecha.

- No cambian colores, borde, sombra, tamaño ni orden de los datos. La tarjeta de muestra mide su alto en vivo y compara las dos.
- «Destacado» va en la cabecera, a la derecha y en la primera fila; la VerificationBadge sigue debajo del nombre. Nunca van pegadas.
- Si el nombre no cabe junto a «Destacado» (a 360, nombres largos), se corta con … en vez de bajar de línea, para que el alto no cambie.
- Lo pagado no salta requisitos ni cambia el orden de los postulantes dentro de una publicación.
- Solo en frames F3. En F1 y F2 no hay tarjetas Premium; PUBL-08 muestra «Premium» con el Badge «Pronto» y no se puede comprar.
