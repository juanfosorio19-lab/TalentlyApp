# IconRules

Las reglas que fijan qué ícono significa qué, en claro y oscuro.

- **IconGear (rueda dentada) = Ajustes**, solo en el AppBar de Perfil. **IconFilter (sliders) = Filtros**, solo en el AppBar de Explorar. Nunca se intercambian.
- Pestañas, en este orden y para cualquier perfil: Inicio (IconHome), Explorar (IconSearch), Actividad (IconCalendar), Mensajes (IconChat), Perfil (IconPerson). Activa en `color-primary-text` con la píldora `color-primary-subtle`; inactiva en `color-text-3`.
- Un ícono por acción: Cerrar = IconClose; Quitar ítem = IconTrash en `color-text-2`; Me interesa = IconLike; Volver = IconArrowLeft; Buscar y Explorar = IconSearch; lo pagado = IconBoost.
- Los 4 tipos de publicación no tienen color propio: se distinguen por ícono y etiqueta (Empleo IconOffers, Turno IconClock, Servicio IconTool, Clase IconBook).
- Todo ícono va con etiqueta visible o, en un IconButton, con nombre accesible.
