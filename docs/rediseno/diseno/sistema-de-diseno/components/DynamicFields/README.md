# DynamicFields

Bloque que dibuja los campos propios de cada oficio o materia. Se ve idéntico en onboarding, publicar, filtros y detalle: mismas etiquetas, mismo orden, mismos íconos.

- Marcado: `.tl-dyn` > `.tl-dyn__head` (overline con el ícono del oficio) + controles de la librería (ChipGroup, MediaUploader documento, MoneyField…); en el detalle, `dl.tl-dyn__read` con ícono, etiqueta y valor.
- Ejemplo guardia de seguridad: «Sistema de turno: 4x4 · 5x2 · 7x7 · 12 h · Rotativo» (una opción al postular, varias al filtrar), «Credencial SPD (ex OS-10)» con exigencia «Obligatoria», y «Dónde has trabajado» (opcional).
- El oficio decide qué se pregunta: a un guardia nunca se le preguntan tecnologías; las tecnologías existen solo en oficios de tecnología.
- Las credenciales obligatorias no se saltan con nada pagado.
