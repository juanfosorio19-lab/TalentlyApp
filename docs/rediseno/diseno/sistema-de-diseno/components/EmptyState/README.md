# EmptyState

Lo que se ve cuando una lista o pantalla no tiene nada que mostrar. Siempre dice por qué y qué hacer: una acción real o una sugerencia útil.

- Marcado: `.tl-empty` > `.tl-empty__icon` (círculo de 72 en `color-surface-2` con un ícono del set de 40 en `color-text-2`) + `h3.tl-empty__title.h3` + `p.tl-empty__text` + acción opcional (Button tonal).
- Usa íconos del set, nunca ilustraciones ni emojis.
- La sugerencia usa datos reales: «No hay turnos en Ñuñoa; hay 8 a menos de 10 km».
- El texto depende de la contraparte: a quien ve ofertas no se le habla de «perfiles».
